# AmirOS — Engineering Intelligence Portfolio Demo

A read-only, synthetic-data executive dashboard that illustrates how **Engineering Intelligence** can turn fragmented technical context into a transparent, human-governed readiness review.

[Open the live demo](https://asajjadi.github.io/engineering-intelligence-amiros-demo/)

## Portfolio materials

- [NovaPump Reliability Review — Synthetic Case Study](CASE_STUDY.md)
- [Portfolio Architecture](ARCHITECTURE.md)

## What this demonstrates

- Context-first engineering questions
- Evidence review, selection, gaps, and traceability
- Structured reasoning with explicit limitations and assumptions
- Deterministic evidence coverage, consistency, validation, and completeness indicators
- Human engineering governance as the final decision authority

## Safe by design

This repository is a public portfolio demonstration separate from the private AmirOS core implementation.

- All project names, records, metrics, and findings are synthetic.
- No credentials, private data, customer information, production integrations, or proprietary code are included.
- The interface is read-only and informational.
- It does **not** issue engineering approvals, authorize production, or replace accountable engineering judgment.

## Run locally

Open `index.html` in a browser. No install, build step, database, or API key is required.
